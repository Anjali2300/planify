# Planify (reorganized)

This repository has been reorganized into a standard client/server layout.

Top-level layout:

- `client/` - React frontend
- `server/` - Node/Express backend

Quick start (development):

Client
```
cd client
npm install
npm start
```

Server
```
cd server
npm install
npm start
```

See `client/README.md` for client details.
